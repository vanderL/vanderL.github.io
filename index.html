Como Autenticar

1

Fazer Login

Envie email e senha para obter o token JWT

2

Incluir Token

Adicione o token no header Authorization: Bearer {token}

3

Fazer Requests

Use o token para acessar endpoints protegidos

Roles e Permissões

USER

Usuário Padrão

  • ✅ GET /users (listar)
  • ✅ GET /me (perfil)
  • ❌ POST /users (criar)
  • ❌ DELETE /users (deletar)
ADMIN

Administrador

  • ✅ Todas as permissões USER
  • ✅ POST /users (criar)
  • ✅ PUT /users/:id (editar)
  • ✅ DELETE /users/:id (deletar)

Arquitetura Clean

Separação clara de responsabilidades em camadas

Fluxo de Dados

Controllers

Camada de Apresentação

Services

Camada de Aplicação

Repositories

Camada de Infraestrutura

Controllers

  • • Receber requests HTTP
  • • Validar entrada com Zod
  • • Retornar responses
  • • Tratar erros específicos

Services

  • • Regras de negócio
  • • Orquestrar repositories
  • • Validar autorização
  • • Processar dados

Repositories

  • • Acesso aos dados
  • • Queries do banco
  • • Abstração de dados
  • • Interface padronizada

Estrutura de Pastas

src/
├── @types/              # Tipos TypeScript customizados
├── app.ts               # Configuração principal do Fastify
├── env/                 # Validação de variáveis de ambiente
├── http/                # 🌐 Camada de Apresentação
│   ├── controllers/     # Controllers organizados por funcionalidade
│   └── middlewares/     # Middlewares (auth, cors, etc)
├── lib/                 # Configurações (Prisma, JWT, etc)
├── repositories/        # 💾 Camada de Infraestrutura
│   ├── fakes/          # Implementações em memória (testes)
│   └── prisma/         # Implementações com Prisma
├── server.ts            # Ponto de entrada
├── services/            # 🧠 Camada de Aplicação
│   ├── errors/         # Classes de erro customizadas
│   ├── factories/      # Factory pattern para DI
│   └── [dominio]/      # Services organizados por domínio
└── utils/               # Utilitários gerais
